\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
Dearly is a Vietnamese Android virtual assistant designed for elderly users and their caregivers. The application accepts recorded speech, transcribes the request, selects an assistant action, and returns both text and a Vietnamese spoken response. Its core security requirement is that a voice request alone must not authorize a sensitive action. Dearly therefore combines automatic speech recognition (ASR), speaker verification (SV), speaker identification (SID), and server-side authorization. A fine-tuned ECAPA-TDNN embedding model supports both one-to-one verification and one-to-many identification \cite{ecapa,speechbrain}; Whisper supports Vietnamese transcription \cite{whisper}.
