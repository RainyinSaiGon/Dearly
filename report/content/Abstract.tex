\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
Dearly is a Vietnamese Android virtual assistant designed for elderly users and their caregivers. The application accepts recorded speech, transcribes the request, selects an assistant action, and returns both text and a Vietnamese spoken response. It provides a safe public ``Ask Dearly'' mode for time, date, and usage guidance before sign-in; personal information remains unavailable in that mode. For authenticated care tasks, Dearly combines automatic speech recognition (ASR), speaker verification (SV), speaker identification (SID), and server-side authorization. A fine-tuned ECAPA-TDNN embedding model supports both one-to-one verification and one-to-many identification \cite{ecapa,speechbrain}; Whisper supports Vietnamese transcription \cite{whisper}. The Android client shows listening state, a level waveform, and a transcript preview; its voice-activity gate discards silent/too-short recordings. For the hands-free medication use case, the elder first says that a named medicine has been taken, then confirms the medicine and scheduled time with a fresh spoken response. Dearly verifies that confirmation recording against the signed-in elder and issues a short-lived one-use grant only after a pass; replayed, too-short, or failed recordings leave medication state unchanged.
